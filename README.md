# RS Screener

RS·SEPA·CANSLIM·기술적 매매 신호를 종목별로 통합해 검색·정렬·필터링하는 정적 웹 스크리너입니다. 네 기능은 별도 페이지로 분리하지 않으며, 프론트엔드는 GitHub Pages에서 실행되고 GitHub Actions가 평일 장 마감 후 KRX 데이터를 갱신합니다. ETF는 대상에서 제외합니다.

## 현재 기능

- 종목명·종목코드·시장·테마 검색
- RS 70/80/90, Minervini Trend Template, VCP, 이동평균 정배열 필터
- SEPA Trend 0~8, 등급, 분기·연간 EPS와 매출 성장 필터
- CANSLIM 0~11 종합 점수, C·A·N·S·L·I·M 상세 구성, ROE 필터
- 포켓 피봇, 신고가 돌파, Dry-up, NR7, ID/NR4, ID/NR7 등 신호 필터
- 52주 고가, RS Line 신고가 근접, RS 70 신규 진입 판정
- 시가총액 구간, 관심종목, 최대 4개 종목 비교 선택
- 다크 모드와 반응형 표
- KR/US 분리 구조(US 데이터는 다음 단계에서 추가)

## RS 계산

63거래일 수익률 40%, 126·189·252거래일 수익률을 각각 20%로 가중한 뒤 유효 종목 집합에서 0~99 백분위로 변환합니다. 252거래일 이력이 없거나 최근 종가가 5,000원 미만인 종목은 공개 목록에서 제외합니다.

## 데이터 갱신

```bash
pip install -r requirements.txt
python scripts/collect_kr.py
```

평일 18:45 KST에 `.github/workflows/update-kr-data.yml`이 자동 실행됩니다. 첫 실행은 전체 가격 이력과 재무 데이터를 수집하므로 시간이 오래 걸릴 수 있습니다. 이후 가격 데이터는 누락 구간만 추가하고, DART 재무 데이터는 같은 공시 기간 안에서 최대 7일간 캐시를 재사용합니다.

가격·거래량으로 계산 가능한 RS, Trend, VCP와 기술 신호를 수집하고, OpenDART의 연결·별도 재무제표로 희석 주당순이익 성장률(분기 YoY), 매출 성장률(분기 YoY), 연간 EPS 성장률과 ROE를 계산합니다. 이 값으로 SEPA 등급과 CANSLIM 점수를 산출합니다. API 키는 저장소 코드가 아니라 GitHub Actions Secret `DART_API_KEY`에 보관합니다.

영업활동 현금흐름과 `(EBITDA−자본지출)/이자비용` 이자보상비율은 후행 12개월(TTM) 기준입니다. 분·반기에는 `최근 연간 금액 + 당기 누적 금액 − 전년 동기 누적 금액`으로 계산하며, EBITDA는 영업이익에 감가상각비와 무형자산상각비를 더해 산출합니다. 자본지출은 유형자산 및 무형자산 취득액의 합계입니다.

시가총액 분류는 3,000억 원 미만을 소형, 3,000억~1조 원 미만을 중형, 1조~10조 원 미만을 중대형, 10조 원 이상을 대형으로 봅니다. `중형 이상` 필터는 시가총액 3,000억 원 이상을 뜻합니다.

## 주의

RS와 파생 신호는 과거 가격 기반의 탐색 도구이며 매수·매도 신호가 아닙니다. KRX 또는 데이터 제공처의 응답 변경, 기업행동, 거래정지 등에 따라 값이 달라질 수 있습니다.
